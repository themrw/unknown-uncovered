Privacy Policy

Last updated: 15 November 2026

"Unknown Uncovered Uploader" is a private tool used only by the owner of the YouTube channel Unknown Uncovered to upload that channel's own videos.

What data the app uses

With the owner's permission, the app uses Google OAuth access to the YouTube Data API to upload videos and read the owner's own channel details. It does not access, collect or store data about any other person.

How data is stored

The access token is stored only as an encrypted secret in the owner's private systems. It is never sold, shared or used for advertising.

Google API Services

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
